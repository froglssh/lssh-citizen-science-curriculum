# 麗山高中公民科學培訓課程 課程子知識庫 (LSSH Citizen Science Curriculum Sub-Wiki)

本儲存庫為**臺北市立麗山高級中學 生物科**「公民科學培訓課程（校本選修／彈性學習）」之專屬課程子知識庫。  
本子庫向上對接母知識庫（`12生物營隊/生物營隊知識庫`），向下落實麗山高中 108 課綱校本正式開課規範（包含高二多元選修每週 3 節 10 週課程、高一彈性學習每週 2 節 18 週課程、麗山校訂課程學生成績評量補充規定、校本學生圖像對齊與學習歷程檔案 OPQN 輔導）。
