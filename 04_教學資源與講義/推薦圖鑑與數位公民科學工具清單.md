# 推薦實體圖鑑與數位公民科學工具清單

本清單為麗山高中公民科學培訓課程師生指定之田野工具與鑑定圖鑑庫。

---

## 一、行動數位公民科學工具 (Mobile Apps & Web Tools)

| 工具名稱 | 支援平台 | 核心功能與課堂應用場景 |
| :--- | :--- | :--- |
| **iNaturalist (愛自然)** | iOS / Android / Web | • 全球最大生物多樣性公眾平台，AI 視覺輔助初判<br>• 照片上傳、座標記錄、社群專家二次確認為「研究級 (Research Grade)」 |
| **eBird (賞鳥記錄)** | iOS / Android / Web | • 康乃爾鳥類學研究室開發，全球鳥類觀測清單登錄<br>• 課堂水鳥與校園鳥類穿越線數據直接回報 |
| **Merlin Bird ID** | iOS / Android | • 聲音辨識 (Sound ID) 功能強大，現場錄製鳥叫聲即時比對鳥種 |
| **中央氣象署 潮汐預報** | App / Web | • 馬岡潮間帶實察必查，取得每日乾潮時刻與大潮週期 |
| **臺灣生物多樣性網絡 (TBN)** | Web (tbn.org.tw) | • 農業部生物多樣性研究所維運，查詢臺灣本土物種受威脅等級與分布圖 |
| **路殺社 (Taiwan Roadkill)** | App / Web | • 臺灣動物路死觀察網，記錄路殺熱點，推動動物通道改善 |

## 二、推薦實體圖鑑與經典專書 (麗山生物科典藏)

### 1. 鳥類與兩棲爬行類
- 《臺灣野鳥手繪圖鑑》（蕭木吉、李政霖／行政院農業委員會林務局、社團法人台北市野鳥學會）—— **賞鳥必備聖經**。
- 《臺灣兩棲爬行類圖鑑》（楊懿如、李鵬鵬／貓頭鷹出版社）—— 阿里磅農場與金面山夜觀必備。

### 2. 海洋與潮間帶生態
- 《臺灣潮間帶生物圖鑑》（李坤瑄、陳育賢／晨星出版社）。
- 《臺灣常見海藻圖鑑》（黃淑芳／國立臺灣博物館）。

### 3. 植物與地質地景
- 《臺灣原生植物全圖鑑》（鐘詩文、許天銓／貓頭鷹出版社）。
- 《臺灣地質之美》（何春蓀／經濟部中央地質調查所）。
